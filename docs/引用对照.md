# 交叉引用对照表

本文件由 `node tools/check-refs.mjs` 生成，不要手改。

正文里的「第 X 条」只记条号不记内容，插入或删除条目会让后面的引用集体错位，
而错位后的条号往往仍在范围内，光查越界抓不到。所以把每处引用**实际指向的标题**
摊开写在这里并入库：改完条目重新生成，`git diff` 里凡是条号没动而标题变了的，
就是被顺延撞歪的引用。
